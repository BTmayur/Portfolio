# Mayur Portfolio | Ready to Host

This folder is the complete static website. It includes the small photo embedded in the HTML, all animations, your project links, and a downloadable resume.

## View locally
Open `index.html` in your browser. Some online AI tool icons require an internet connection.

## Replace your resume
1. Open `assets/`.
2. Replace **Mayur_Resume.pdf** with your newest resume PDF, preserving the exact filename.
3. Republish/commit the updated PDF on GitHub. Both Download Resume buttons will use the new file automatically.

**Important:** The included PDF is the previously uploaded resume. The newer GTRE metrics and Thirumala Construction role appear on the website but may not yet be present in this PDF. Replace it with your updated resume before sharing the site publicly.

## Host on GitHub Pages (free)
1. On GitHub while logged into `BTmayur`, create a repository called **BTmayur.github.io**, choosing **Public**.
2. Extract `Mayur_Portfolio_Ready_To_Host.zip`, and upload **index.html**, **assets/** (including the PDF), and **.nojekyll** to the *root* of the repository. Do not upload the containing folder as a single nested folder. The README is optional.
3. Click **Commit changes**.
4. Open **Settings > Pages**, choose **Deploy from a branch**, choose **main** and **/(root)**, then click **Save**.
5. After deployment, your site should be at **https://BTmayur.github.io/**.
6. Visit the site and test both Download Resume buttons.

If you prefer the repo `mayur-portfolio`, the project Pages URL will instead be `https://BTmayur.github.io/mayur-portfolio/`.

## Standalone file
`Mayur_Portfolio_Updated_Standalone.html` is supplied separately. It embeds the uploaded PDF and portrait so you can open it without extracting the website ZIP. For hosting, use the ZIP rather than the standalone HTML.
